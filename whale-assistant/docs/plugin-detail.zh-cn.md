# DSH 小鲸鱼（dsh-whale-assistant）

DeepSeek Harness 的陪伴/通知插件：任务完成与失败通知、用量报告、历史任务抽屉，以及一只以**整个桌面**为边界的屏幕级小鲸鱼（桌宠模式）。

## 🐋 桌宠模式（默认开启）

- **屏幕级常驻**：小鲸鱼默认游在桌面上（不限于 DSH 窗口内），可拖到任意位置，双击游回角落
- **关窗 ≠ 退出**：点 DSH 右下角 × 关闭窗口后，小鲸鱼**留在桌面上**，后台任务完成照常通知；真正退出 DSH（或升级）时它才会跟着消失
- **右键菜单三种形态**：🐋 完整形态 ｜ 🫧 缩成气泡 ｜ 🙈 隐藏小鲸鱼（躲猫猫——右下角留一枚小气泡，点一下鲸鱼从气泡里冒出来）
- DSH 窗口内的小鲸鱼在桌宠运行期间自动休眠，两者永不重复出现

## 🔔 通知

- **任务完成/失败**：真名播报（如「[流程测试 1] 完成了 🎉」）+ 三行用量报告（本轮 / 全对话累计 / 上下文已用 %）+ 提示音
- **需要你介入**：🤔 提问（ask_user_question）与 ⚠️ 审核（工具审批）都会提醒
- **红标角标**：未读通知计数，点击读回、双击跳转

## 🎯 跳转与历史

- **双击通知**：直接跳到**那条任务的消息**（翻页回溯定位，不是只打开对话）
- **右键菜单 → 📜 历史任务**：最近记录抽屉（含耗时与用量），开着时实时跟随新任务；点任意一条同样跳到对应任务节点

## ❓ 常见问题

- **DSH 关了小鲸鱼还在**：正常——关窗只是关页面，退出 DSH 时它才会消失；右键菜单 →「❌ 退出桌宠」可手动关闭
- **通知显示「任务 N」**：该对话还没有名字（新会话首轮任务），名字生成后会自动改写
- **小鲸鱼不见了**：DSH 被真正退出时它会跟随消失，重新打开 DSH 即回归
